# Discover Query — Validating Failed SSH Logins

## Query used (Kibana Discover)

```
agent.name: "linuxt" and system.auth.ssh.event: "Failed"
```

## Result
All failed login attempts generated by the Hydra run in `attack-simulation/` appeared
in Discover with correct timestamps, matching the attack window. This confirmed the
full pipeline was working end-to-end:

Kali (attack) -> linuxt sshd (auth log) -> Elastic Agent (log shipping) ->
Elasticsearch (indexing) -> Kibana Discover (queryable)

## Live monitoring during the attack (optional, done on `linuxt`)

```bash
sudo tail -f /var/log/auth.log
# or, if auth.log doesn't exist on this Ubuntu version:
sudo journalctl -fu ssh
```
