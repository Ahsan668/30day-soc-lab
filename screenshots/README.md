# Screenshots

Supporting screenshots for each section of this repo. See `SCREENSHOT_CHECKLIST.md` in
the repo root for exactly what to capture, how to name each file, and which folder's
README to reference it from.

## Naming convention

```
<section-prefix>-<short-description>.png
```

Examples: `network-enp0s8-down.png`, `elastic-fleet-offline.png`,
`attack-hydra-running.png`, `detection-discover-failed-logins.png`,
`dashboard-failed-logins-timeline.png`
